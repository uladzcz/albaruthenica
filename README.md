# 🗺️ Albaruthenica — Беларускія мясціны свету

> **Albaruthenica** — адкрытая інтэрактыўная картаграфічная ініцыятыва па зборы, захаванні і візуалізацыі беларускіх гістарычных месцаў, помнікаў, пахаванняў выбітных дзеячаў, храмаў і культурных асяродкаў па ўсім свеце.

Ад віленскіх муроў і пражскай друкарні Францыска Скарыны да беларускіх цэркваў Лондана, некропаляў у ЗША і слядоў Ігната Дамейкі ў Чылі.

---

## ✨ Асаблівасці праекта

- 🌍 **Сусветная інтэрактыўная мапа** на базе [Leaflet.js](https://leafletjs.com/) і сучасных хуткіх тайлаў CartoDB Voyager без неабходнасці ключоў API.
- 🗂️ **Зручная кластарызацыя і фільтры:** па катэгорыях (*Памятнікі, Пахаванні, Храмы, Музеі і культура, Гістарычныя мясціны, Мемарыяльныя дошкі*).
- 🔍 **Хуткі паўнатэкставы пошук** па назве, горадзе, краіне, тэгах і гістарычным апісанні.
- 🌐 **Мультымоўнасць (i18n):** падтрымка беларускай (асноўная), рускай і англійскай моў.
- 📱 **Цалкам адаптыўны дызайн:** зручна праглядаць як на вялікіх экранах, так і на смартфонах.
- 🔗 **Прамыя спасылкі:** кожнае месца мае свой уласны URL-хэш (напрыклад `#place=skaryna-prague-monument`), якім лёгка дзяліцца ў сацсетках.
- 🛠️ **Убудаваны генератар новых мясцін:** націснуўшы «Дадаць месца», можна клікнуць на карту для аўтаматычнага вызначэння каардынат і атрымаць гатовы JSON для рэпазіторыя.

## 🚀 Як апублікаваць сайт на GitHub Pages

Сайт зроблены цалкам на чыстым сучасным вэбе (HTML/CSS/JS) і **не патрабуе ніякіх зборшчыкаў ці налад сервера**. Ён запускаецца імгненна!

### Крок 1. Стварыце рэпазіторый на GitHub
1. Перайдзіце на [GitHub.com](https://github.com/) і націсніце **New repository**.
2. Назавіце яго, напрыклад, `albaruthenica` (або `<ваш-юзернейм>.github.io`, калі хочаце зрабіць яго галоўным сайтам).
3. Зрабіце рэпазіторый **Public**.

### Крок 2. Запампуйце файлы ў рэпазіторый
Выканайце ў тэрмінале ў тэчцы праекта:
```bash
git init
git add .
git commit -m "Initial release of Albaruthenica"
git branch -M main
git remote add origin https://github.com/<ваш-юзернейм>/albaruthenica.git
git push -u origin main
```

### Крок 3. Уключыце GitHub Pages
1. У вашым рэпазіторыі на GitHub адкрыйце ўкладку **Settings** (Налады).
2. Злева ў меню выберыце **Pages**.
3. У раздзеле **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / папка: `/ (root)`
4. Націсніце **Save**.
5. Праз 1–2 хвіліны ваш сайт будзе даступны па адрасе:
   ```text
   https://<ваш-юзернейм>.github.io/albaruthenica/
   ```

## 📍 Як дадаваць новыя месцы

Усе звесткі пра мясціны захоўваюцца ў файле [`data/places.json`](data/places.json).

### Спосаб 1. Праз інтэрфейс сайта (найпрасцейшы)
1. Адкрыйце сайт і націсніце кнопку **«Дадаць месца»** у правым верхнім куце.
2. Націсніце кнопку **«Выбраць каардынаты клікам на карце»** і клікніце ў патрэбную кропку на карце.
3. Запоўніце назву і апісанне.
4. Націсніце **«Згенераваць JSON»** і потым **«Скапіяваць JSON»**.
5. Устаўце скапіяваны блок у файл `data/places.json`.

### Спосаб 2. Рэдагаванне `data/places.json` наўпрост
Кожны запіс мае наступны фармат:

```json
{
  "id": "унікальны-ідэнтыфікатар",
  "title": {
    "by": "Назва па-беларуску",
    "ru": "Название по-русски",
    "en": "Name in English"
  },
  "category": "monument",
  "country": {
    "by": "Польшча",
    "ru": "Польша",
    "en": "Poland"
  },
  "city": {
    "by": "Варшава",
    "ru": "Варшава",
    "en": "Warsaw"
  },
  "coordinates": [52.2393, 21.0028],
  "description": {
    "by": "Гістарычнае апісанне па-беларуску...",
    "ru": "Описание по-русски...",
    "en": "Description in English..."
  },
  "image": "https://example.com/image.jpg",
  "links": [
    {
      "title": "Вікіпедыя",
      "url": "https://be.wikipedia.org/..."
    }
  ],
  "tags": ["Тэг1", "Тэг2"]
}
```

#### Даступныя катэгорыі (`category`):
- `monument` — Памятнікі
- `grave` — Пахаванні / Некрапалі
- `church` — Храмы і святыні
- `culture` — Музеі і культурныя асяродкі
- `historical` — Гістарычныя будынкі і мясціны
- `plaque` — Мемарыяльныя дошкі

## 💻 Лакальны запуск для распрацоўкі

Каб адкрыць і пратэставаць сайт на сваім камп'ютары:

Калі ўсталяваны Python:
```bash
python -m http.server 8000
```
Пасля чаго адкрыйце ў браўзеры: [http://localhost:8000](http://localhost:8000).
